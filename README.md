# 🤖 Project AURA

**AURA** (Autonomous Edge-AI Robotic Architecture) is an integrated mobile control dashboard and telemetry unit designed for real-time edge computing, robotic control (ROS 2), and live monitoring.

---

## 🏗️ Architecture Overview

* **Frontend:** React + Vite + TypeScript (Tailwind CSS)
* **Mobile Wrapper:** Android Studio / Capacitor (Native APK Integration)
* **Edge Backend:** FastAPI & ROS 2 running on Raspberry Pi 5 / NVIDIA Jetson
* **Deployment:** Hosted live via GitHub Pages at `powerdreams.top`
